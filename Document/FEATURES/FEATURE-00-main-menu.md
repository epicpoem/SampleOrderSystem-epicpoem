# FEATURE-00: 메인 메뉴 및 시스템 현황 요약

## 기능 목적

시스템 진입 시 전체 현황을 한눈에 파악하고, 6개 기능 메뉴로 이동할 수 있는 메인 화면을 제공한다.

## 사용자 시나리오

1. 시스템 실행 시 메인 메뉴 화면 표시
2. 시스템 현황 요약 정보 확인
3. 원하는 메뉴 번호 입력 후 해당 기능으로 이동
4. [0] 종료 선택 시 데이터를 저장하고 시스템 종료

## 출력 정보

### 시스템 현황 요약 (항상 표시)

| 항목 | 설명 |
|------|------|
| 현재 일시 | 시스템 현재 시각 |
| 등록 시료 수 | 시스템에 등록된 시료 종류 수 |
| 총 재고 | 전체 시료 재고 합계 (ea) |
| 전체 주문 수 | 전체 주문 건수 (REJECTED 포함) |
| 생산라인 대기 수 | PRODUCING 상태 주문 건수 |

### 메뉴 목록

| 번호 | 메뉴명 | 기능 요약 |
|------|--------|-----------|
| [1] | 시료 관리 | 시료 등록 / 목록 조회 / 검색 |
| [2] | 시료 주문 | 고객 주문 접수 (RESERVED 생성) |
| [3] | 주문 승인/거절 | RESERVED 주문 승인·거절 처리 |
| [4] | 모니터링 | 상태별 주문 수 + 시료별 재고 현황 |
| [5] | 생산라인 조회 | 현재 생산 중 + 대기 큐 확인 |
| [6] | 출고 처리 | CONFIRMED 주문 출고 실행 |
| [0] | 종료 | 데이터 저장 후 시스템 종료 |

## 예외 처리

- 유효하지 않은 메뉴 번호 입력 시: 재입력 유도

## 정책

- 메인 메뉴로 복귀할 때마다 시스템 현황 요약은 최신 상태로 갱신된다.
- [0] 종료 선택 시 데이터를 JSON 파일에 저장한 후 종료한다.
