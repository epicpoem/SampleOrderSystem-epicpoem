# FEATURE-06: 출고 처리

## 기능 목적

출고 대기(CONFIRMED) 상태의 주문을 최종 출고 처리하여 고객에게 납품 완료 상태로 전환한다.

## 사용자 시나리오

1. 메인 메뉴에서 [6] 출고 처리 선택
2. CONFIRMED 상태의 주문 목록 표시
3. 출고할 주문 번호 입력
4. 출고 처리 완료 메시지 출력 (주문번호, 출고 수량, 처리 일시, 상태 전환 결과)

## 입력

- 출고할 주문의 선택 번호

## 출력

- 주문번호
- 출고 수량 (주문 수량과 동일)
- 처리 일시
- 상태 전환: CONFIRMED → RELEASE

## 예외 처리

- 출고 가능한 주문(CONFIRMED)이 없는 경우: "출고 가능한 주문이 없습니다." 안내
- 잘못된 번호 입력 시: 재입력 유도

## 정책

### CONFIRMED 상태의 의미
- CONFIRMED 상태는 "재고 확보 완료"를 의미한다.
  - 경로 1: 승인 시점에 재고가 충분하여 즉시 CONFIRMED 전환된 주문
  - 경로 2: 재고 부족으로 PRODUCING 전환 → 생산 완료 후 CONFIRMED 전환된 주문
- 출고 처리 시 별도로 재고를 재확인하지 않는다.

### 재고 차감
- 출고 처리(RELEASE 전환) 시 해당 시료의 재고에서 **주문 수량만큼** 차감된다.
- 재고의 실시간 생산량 반영(진행분 비례 계산)은 출고 시점에 적용하지 않는다.

### 출고 처리 가능 조건
- 반드시 CONFIRMED 상태인 주문만 출고 처리할 수 있다.
- PRODUCING 중인 주문은 생산이 완전히 완료되어 CONFIRMED로 전환된 이후에만 출고 처리 가능하다.
