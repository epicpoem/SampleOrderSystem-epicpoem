# FEATURE-03: 주문 승인/거절

## 기능 목적

예약(RESERVED) 상태의 주문을 검토하여 승인하거나 거절한다. 승인 시 현재 물리적 재고를 기준으로 즉시 출고 대기(CONFIRMED) 또는 생산 중(PRODUCING)으로 자동 분기된다.

## 사용자 시나리오

### 시나리오 A: 재고 충분 → CONFIRMED

1. 메인 메뉴에서 [3] 주문 승인/거절 선택
2. RESERVED 상태 주문 목록 확인
3. 승인할 주문 번호 입력
4. 시스템이 물리적 재고 확인: 재고 >= 주문 수량
5. 즉시 CONFIRMED 전환 완료 메시지 출력

### 시나리오 B: 재고 부족 → PRODUCING

1. 메인 메뉴에서 [3] 주문 승인/거절 선택
2. RESERVED 상태 주문 목록 확인
3. 승인할 주문 번호 입력
4. 시스템이 물리적 재고 확인: 재고 < 주문 수량
5. 부족분, 실생산량, 예상 생산 소요 시간 표시
6. [Y] 승인 또는 [N] 거절 선택
7. [Y] 선택 시: PRODUCING 전환 + 생산라인 자동 등록 완료 메시지 출력

### 시나리오 C: 주문 거절

1. RESERVED 상태 주문 목록에서 거절할 주문 번호 입력
2. [N] 선택 또는 별도 거절 처리
3. REJECTED 전환 완료 메시지 출력

## 입력

- 처리할 주문 번호 (목록의 선택 번호)
- 승인 여부 확인 입력 ([Y]/[N])

## 출력

- 승인 → CONFIRMED: 상태 전환 완료 메시지
- 승인 → PRODUCING: 부족분, 실생산량, 총 생산 시간, 상태 전환 완료 메시지
- 거절 → REJECTED: 상태 전환 완료 메시지

## 예외 처리

- RESERVED 주문이 없는 경우: "승인 대기 중인 주문이 없습니다." 안내
- 잘못된 번호 입력 시: 재입력 유도

## 정책

### 물리적 재고 실시간 계산 (승인 시점에만 적용)
```
PRODUCING 주문 1건의 진행분 = 실생산량 × (경과시간 / 총생산시간)
                              (경과시간 >= 총생산시간이면 실생산량 전체)
물리적 재고(실시간)         = 보유 재고 + 각 PRODUCING 주문의 진행분 합산
부족분                      = 주문 수량 - 물리적 재고(실시간)
```

### 생산량 계산 (재고 부족 시)
```
실 생산량    = ceil(부족분 / (수율 × 0.9))
총 생산시간  = 평균 생산시간(min/ea) × 실 생산량
```

### 결정 시점 고정
- 생산 여부(재고 충분/부족 분기)는 **주문 승인 시점에만** 판단한다.
- 이미 CONFIRMED 또는 PRODUCING으로 전환된 주문은 이후 재고 변동이 발생해도 상태를 소급 재계산하지 않는다.
- 생산 수량도 **승인 시점에 계산된 값으로 고정**된다.

### 재고 차감 시점
- CONFIRMED 전환 시: 재고 차감 없음
- RELEASE 처리 시: 주문 수량만큼 재고에서 차감
