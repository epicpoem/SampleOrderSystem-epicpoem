# FEATURE-04: 모니터링

## 기능 목적

시스템의 전체 현황을 한눈에 파악할 수 있도록 상태별 주문 건수와 시료별 재고 상태를 제공한다.

## 하위 기능

### 1. 주문량 확인

**목적**: 현재 각 상태별 주문 건수를 확인한다.

**사용자 시나리오**:
1. 메인 메뉴에서 [4] 모니터링 선택
2. [1] 주문량 확인 선택
3. 상태별 주문 건수 출력

**출력 정보**:
| 상태 | 설명 |
|------|------|
| RESERVED | 승인 대기 중인 주문 수 |
| CONFIRMED | 출고 대기 중인 주문 수 |
| PRODUCING | 생산 중인 주문 수 |
| RELEASE | 출고 완료된 주문 수 |

**정책**:
- REJECTED(거절) 상태는 집계에서 제외한다.

---

### 2. 재고량 확인

**목적**: 시료별 현재 재고 수량과 재고 상태를 확인한다.

**사용자 시나리오**:
1. 모니터링 메뉴에서 [2] 재고량 확인 선택
2. 전체 시료의 재고 현황 테이블 출력

**출력 정보**: 시료명, 현재 재고 수량, 재고 상태

**재고 상태 기준**:
| 상태 | 조건 |
|------|------|
| 고갈 | 재고 수량이 0 |
| 부족 | 재고 수량 > 0이지만 주문 대비 부족 |
| 여유 | 주문 대비 재고 충분 |

**정책**:
- "주문 대비" 판단 기준: **CONFIRMED + PRODUCING** 상태 주문의 총 주문량과 현재 재고를 비교한다.
- RESERVED 주문은 아직 거절될 수 있으므로 재고 판단에서 제외한다.
- 고갈 여부는 수량 기준(0)으로 먼저 판단하고, 이후 부족 여부를 판단한다.
- **물리적 재고(실시간)** 를 사용한다: `physStock = sample.stock + Σ(PRODUCING 진행분)`
  - PRODUCING 중인 주문의 진행 비례 생산량을 실시간으로 재고에 반영한다.
  - 모니터링 화면 진입 시마다 최신 물리적 재고가 계산된다.

### 3. 잔여율 그래프

**목적**: 시료별 현재 재고가 주문량 대비 몇 %를 커버하는지 시각적 막대 그래프로 표시한다.

**표시 형식**:
```
[██████░░░░]  60%
```
- 막대 폭: 10칸, 각 1칸 = 10%
- `잔여율 = min(100, physStock / CONFIRMED+PRODUCING 주문량 * 100)`
- 주문량이 0인 경우: 100% (미출하 재고)

**재고 상태별 기대 잔여율**:
| 상태 | 잔여율 범위 |
|------|------------|
| 여유 | 100% |
| 부족 | 1% ~ 99% |
| 고갈 | 0% |

## 예외 처리

- 등록된 시료가 없는 경우: "등록된 시료가 없습니다." 안내
- 주문 데이터가 없는 경우: 모든 상태 카운트를 0으로 표시
