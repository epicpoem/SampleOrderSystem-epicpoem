# FEATURE-01: 시료 관리

## 기능 목적

시스템에서 주문 가능한 시료(Sample)를 등록하고 관리한다. 등록된 시료만 주문이 가능하므로, 시료 관리는 시스템의 기반이 되는 기능이다.

## 하위 기능

### 1. 시료 등록

**목적**: 새로운 시료를 시스템에 추가한다.

**사용자 시나리오**:
1. 메인 메뉴에서 [1] 시료 관리 선택
2. [1] 시료 등록 선택
3. 시료 ID 입력 (예: S-006)
4. 시료 이름 입력 (예: 질화갈륨 기판-2인치)
5. 평균 생산시간 입력 (단위: min/ea, 예: 0.7)
6. 수율 입력 (0 초과 1 이하, 예: 0.85)
7. 입력 내용 확인 후 등록 완료

**입력**:
- 시료 ID: 고유 식별자 (문자열, 예: S-001)
- 이름: 시료 명칭 (문자열)
- 평균 생산시간: 1개당 생산에 걸리는 시간 (실수, 단위: min/ea)
- 수율: 정상품 비율 (실수, 0 < 수율 ≤ 1)

**출력**: 등록 완료 메시지 및 부여된 시료 정보 요약

**예외 처리**:
- 이미 존재하는 ID 입력 시: "이미 등록된 시료 ID입니다." 안내 후 재입력 유도
- 수율 범위 초과(0 이하 또는 1 초과) 시: 유효성 오류 안내 후 재입력 유도
- 생산시간 0 이하 입력 시: 유효성 오류 안내 후 재입력 유도

**정책**:
- 등록 시 초기 재고는 항상 0으로 설정된다.

---

### 2. 시료 목록 조회

**목적**: 등록된 모든 시료와 현재 재고 수량을 확인한다.

**사용자 시나리오**:
1. 시료 관리 메뉴에서 [2] 시료 목록 선택
2. 전체 시료 목록이 테이블 형식으로 출력됨

**출력 정보**: 시료 ID, 이름, 평균 생산시간, 수율, 현재 재고 수량

**예외 처리**:
- 등록된 시료가 없는 경우: "등록된 시료가 없습니다." 안내

---

### 3. 시료 검색

**목적**: 특정 속성 조건으로 시료를 검색하여 빠르게 찾는다.

**사용자 시나리오**:
1. 시료 관리 메뉴에서 [3] 시료 검색 선택
2. 검색 기준 속성 선택 (ID / 이름 / 수율)
3. 검색어(값) 입력
4. 조건에 맞는 시료 목록 출력

**입력**: 검색 대상 속성 선택 + 검색어

**출력**: 조건에 맞는 시료 목록 (없으면 "검색 결과가 없습니다.")

**정책**:
- 검색 가능한 속성은 **ID, 이름, 수율** 3가지로 고정한다.
- 사용자가 검색 대상 속성을 직접 선택한 후 검색어를 입력한다.

**예외 처리**:
- 검색 결과가 없는 경우: "검색 결과가 없습니다." 안내
