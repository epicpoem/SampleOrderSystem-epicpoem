# FEATURE-05: 생산라인 조회

## 기능 목적

현재 생산 중인 주문의 진행 상황과 생산 대기 중인 주문 목록을 FIFO 순서로 확인한다. 메뉴 진입 시점에 경과 시간을 계산하여 생산 완료 여부를 자동 감지한다.

## 사용자 시나리오

1. 메인 메뉴에서 [5] 생산라인 조회 선택
2. 시스템이 현재 시각 기준으로 생산 진행 상태 계산
   - 생산 완료된 주문은 자동으로 CONFIRMED 전환
3. 현재 생산 중인 주문 정보 표시
4. 대기 중인 주문 목록 FIFO 순서로 표시

## 출력 정보

### 현재 생산 중 (단일 라인)
- 주문번호
- 시료명
- 주문량, 현재 재고, 부족분, 실생산량
- 현재 진행률 (%)
- 완료 예정 일시

### 대기 큐 (FIFO 순)
- 순서, 주문번호, 시료명, 주문량, 부족분, 실생산량, 예상 완료 일시

## 예외 처리

- 생산 중인 주문이 없는 경우: "현재 생산 중인 주문이 없습니다." 안내
- 대기 중인 주문이 없는 경우: "대기 중인 주문이 없습니다." 안내

## 정책

### 스케줄링
- 단일 생산라인, FIFO(선입선출) 방식으로 처리한다.
- 가장 먼저 PRODUCING 상태로 전환된 주문이 먼저 생산된다.

### 생산 완료 감지 (Q4 정책)
- 별도 백그라운드 스레드를 사용하지 않는다.
- **어느 메뉴에 진입하더라도** 경과 시간을 확인하여 완료된 주문을 PRODUCING → CONFIRMED 으로 자동 전환해도 무방하다.
- 단일 라인이므로 큐의 앞 주문이 완료되면 다음 주문의 생산 시작 시각이 결정된다.

### 진행률 계산
```
진행률(%) = (경과 시간 / 총 생산 시간) × 100  (최대 100%)
```

### 시간 처리
- 실제 환경에서는 시스템 시각(SystemClock)을 사용한다.
- 테스트 환경에서는 시간을 임의로 설정할 수 있는 FakeClock을 주입하여 테스트한다.
