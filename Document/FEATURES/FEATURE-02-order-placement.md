# FEATURE-02: 시료 주문 (접수)

## 기능 목적

고객의 시료 요청을 시스템에 주문으로 접수한다. 접수된 주문은 이후 승인/거절 단계에서 처리된다.

## 사용자 시나리오

1. 메인 메뉴에서 [2] 시료 주문 선택
2. 시료 ID 입력 (예: S-003)
3. 고객명 입력 (예: 삼성전자 파운드리)
4. 주문 수량 입력 (예: 200)
5. 입력 내용 확인 화면 표시
6. [Y] 예약 접수 또는 [N] 취소 선택
7. 접수 완료 시 주문번호 및 현재 상태 출력

## 입력

- 시료 ID: 등록된 시료의 ID
- 고객명: 주문 고객의 이름 또는 회사명
- 주문 수량: 1 이상의 정수 (단위: ea)

## 출력

- 접수 완료 메시지
- 자동 부여된 주문번호 (형식: `ORD-YYYYMMDD-XXXX`)
  - 날짜별 순번 4자리 (당일 첫 주문: 0001부터 시작)
- 현재 주문 상태: RESERVED

## 예외 처리

- 존재하지 않는 시료 ID 입력 시: "등록되지 않은 시료 ID입니다." 안내 후 재입력 유도
- 수량 0 이하 입력 시: 유효성 오류 안내 후 재입력 유도
- [N] 취소 선택 시: 주문 접수 없이 메뉴로 복귀

## 정책

- 주문 접수 시점에는 재고 확인을 하지 않는다.
- 재고 확인 및 승인 처리는 [3] 주문 승인/거절 메뉴에서 별도로 수행한다.
- 동일 날짜에 여러 주문이 접수되더라도 순번이 중복되지 않는다.
